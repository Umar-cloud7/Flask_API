  - Full debugging capabilities

docker run -p 3000:3000 -e REACT_APP_API_URL=http://your-backend:5000 task-frontend:1.0

Access:
  Frontend: http://localhost:3000

Features:
  - Isolated deployment
  - Production-like environment
  - Easy to scale
